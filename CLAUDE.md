# ai-office-shared

Общий пакет офиса ботов + Силли (`agents/coder.py`), её оркестратор.
Этот файл читает КАЖДАЯ сессия автоматически — поэтому здесь оглавление, а не
рассказ. Подробности живут в коде и в `lessons/lessons.json`.

## Инварианты

Восемь правил, которые нельзя нарушать не подумав. Меняешь любое — запиши
решение (см. «История решений»).

1. **`agents/coder.py` правится только вручную:** ветка → PR → ревью Влада →
   мёрдж. Никаких `dev_task` на этот файл. Инцидент 01.07.2026: гейт пропустил
   8-строчную заглушку вместо файла на 5766 строк и уронил офис целиком.
   Запрет живёт в коде — `dev_queue.self_edit_refusal`, — а не в промте.
2. **Каждый коммит сюда = ~90 секунд простоя Силли.** Копи правки, не мёржи по
   одной.
3. **Данные → Redis, код → GitHub.** Никогда наоборот.
4. **Гейт не отчитывается «пройдено», не исполнившись.** Проверка, которой не
   на чем было запуститься, — провал, а не пропуск.
5. **Кто сделал работу, тот её не принимает.** Улику об успехе подписывает
   проверяющий или детерминированный гейт, не исполнитель.
6. **У каждой петли ретраев есть потолок, и он кончается человеком.**
7. **Совпадение по слову, а не по подстроке.** «били» внутри «побили» — не
   Билли, `up` внутри `updated_at` — не запрос метрик.
8. **Провал называет того, кто упал.** Не выдумывай причину: если дальняя
   сторона сказала, почему упала, — цитируй; промолчала — так и скажи.

## История решений

`lessons/lessons.json` — один файл, два вида записей, различает `kind`:

- `lesson` — что сломалось, почему архитектура это допустила, как чинили;
- `decision` — какой выбор сделан, почему, что отвергнуто.

Схема и правила — `lessons/SCHEMA.md`. Записи привязываются к коду полем
`anchors` (`файл.py:symbol`), и `tests/test_lesson_anchors.py` следит, чтобы
якоря указывали на живой код.

**Запись обязательна в двух случаях:** правка меняет инвариант из этого файла,
либо противоречит уже записанному решению. Остальное — в коммит-мессадж.

## Перед правкой

```bash
python3 -m pytest tests/ -q
python3 -m pyflakes $(git ls-files '*.py' ':!agents/*')
python3 -m compileall -q agents/coder.py      # coder.py исключён из линта CI
```

`agents/coder.py` невозможно импортировать в тест (на уровне модуля читается
`os.environ`, поднимается aiogram). Поэтому всё, что должно быть покрыто
тестами, живёт в пакете, а не в нём; функции самого `coder.py` тесты достают
через AST — образец в `tests/test_ricky_code.py`.

## Внешние источники

- Notion — повествование по сессиям и открытые дефекты. Порядок обновления и
  правила офиса — на странице «CLAUDE — СТАРТ».
- Силли отвечает на `https://ai-office-shared-production.up.railway.app`.
  Без токена доступны `GET /health`, `/version`, `/envcheck`, `/logs`, `POST /task`.
  `POST /redis` и `GET /secrets` требуют её `RAILWAY_TOKEN_VLAD`.

  **Тело задачи — `{"message": "...", "agent": "Claude", "source": "CLAUDE"}`.**
  Работа берётся из `message`; поле названо здесь потому, что 02.09.2026 сессия
  дважды прислала её в `task`, дважды получила `done` с приветствием Силли и
  полчаса искала дефект в офисе вместо своего вызова. Теперь такой запрос
  отвергается с 400 и текстом, называющим поле (`shared/task_request.py`), но
  дешевле не промахнуться.

- **Смёржено ≠ работает.** Между main и тем, что видит человек, стоит деплой.
  `GET /health` отвечает одинаково до и после, поэтому версию спрашивают у
  `GET /version`: он отдаёт SHA сервиса и SHA установленного пакета
  (`shared/build_info.py`). Отвечают Силли, Крисс и все воркеры отдела; путь
  открыт без токена намеренно — проверка, которой нужен секрет офиса, не
  независима. Проверять после каждого деплоя: «задеплоено» из уст исполнителя
  уликой не является (инвариант 5).
